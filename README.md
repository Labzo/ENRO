# ENRO – Europ Night Racing Online

Európai Éjszakai Futam Online. Igor kedvence. Propagandaszatíra: a célpont az apparátus, nem az orosz nép.

Pitch-demó v0.1: egyjátékos, böngészőben, fiók nélkül (mentés a böngészőben).

## Ami benne van
- Karakterválasztó szovjet hivatali űrlap: kék nő (+2 kijelzett Skill COIN), piros férfi (−2), sárga android (egyenletes, «Гражданин № 0417»). A valós hatás azonos: «Коэффициент равенства 1,00».
- Szláv eredetű nevek magyar és orosz alakkal; a név jelentése adja a kiemelt ágat.
- Egy városi kör (Budapest), Labzo 2026-10-31-i menete szerint: Night 1 → Day 1 → Night 2 (versenyző vagy proli ág, Igor választ) → Day 2 → Day 3 indulás.
- Seed-es futam: ugyanaz a seed mindenhol ugyanazt a futamot adja. Vodka vagy tea, «Глаз», ajtó, torpedó, a csaló mindig nyer.
- Bank: КриптоРубль → € váltás a 65%-os levonással.
- Magyar és angol felület, az orosz feliratok maradnak.

## Ami még hiányzik (következő lépések)
- Valós OSM-térkép és útvonalak (MapLibre + PMTiles, OSRM), Labzo gépén előállítva.
- Ink-alapú visual novel jelenetek, babuskák, friend-sztori, Interpol-szál.
- Pozsony (Map 02) és a vonatút.
- Online mód: szerver + beépített 01-es kliens.

## Futtatás
```
npm install
npm run dev
npm run build   # dist/ bármilyen statikus tárhelyre
```
